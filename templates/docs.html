{{ section("01", "intro", "Introduction") }}

1.1 Purpose

ReturnLoop gives an online store one place to run every return: from the customer's request and the doorstep pickup, through quality check and grading, to a correct refund and the item going back on the shelf, to the repair bench or to scrap. Every step is recorded.

1.2 Scope

IN SCOPE

  • Six roles and a 13-status return workflow
  • Eligibility rules, pickup booking with two attempts
  • QC checklist, A / B / C grading, fraud check
  • Refurbishing and re-inspection
  • Refund calculation and inventory log
  • Admin dashboard and frequent-returner flags

OUT OF SCOPE

  • Real payments or a payment gateway
  • Passwords and real accounts (a role switcher stands in)
  • Courier API integration

1.4 Key terms

Return code
The ID of a return, e.g. RL-2026-0004.
Grade A / B / C
QC's verdict: A restocked (100%), B repaired then rechecked (70%), C scrapped (0%).
Handoff
After each step the app names the next desk and opens its page in one click.
Return window
7 days from delivery; outside it, the item can't be returned.
